Technical Foundations of WebAudio Fingerprinting

What the WebAudio API Provides

  • AudioContext: the entry point for creating audio graphs.
  • GainNode: controls signal amplitude; values ≤ 0.0001 render tones inaudible.
  • OscillatorNode: generates periodic waveforms; can be phase-shifted.
  • AnalyserNode: extracts frequency-domain data via Fast Fourier Transform (FFT).

How Audio Signals Reveal Hardware Traits

  • Speaker and microphone resonances differ across devices, affecting the spectral output captured by the AnalyserNode.
  • Clock drift in the audio hardware introduces subtle timing variations that survive FFT analysis.
  • Digital-to-Analog converters (DACs) imprint unique quantization noise, which the fingerprinting script can detect.

Therefore, the combination of these hardware fingerprints yields a high-entropy identifier that complements traditional canvas or font metrics.

Implementation Details on AliExpress

Constructing a Silent Audio Graph

  1. Create an AudioContext
const ctx = new (window.AudioContext || window.webkitAudioContext)({ latencyHint: "interactive" });
  1. Add a low-gain GainNode
const gain = ctx.createGain();
gain.gain.value = 0.00005; // well below hearing threshold
  1. Generate two out-of-phase oscillators
const oscA = ctx.createOscillator();
const oscB = ctx.createOscillator();
oscA.frequency.value = 19000; // sub-audible
oscB.frequency.value = 19000;
oscB.phase = Math.PI; // 180° phase shift
  1. Connect nodes to form a silent composite
oscA.connect(gain);
oscB.connect(gain);
gain.connect(ctx.destination);
  1. Attach an AnalyserNode for data capture
const analyser = ctx.createAnalyser();
analyser.fftSize = 32768;
gain.connect(analyser);

Therefore, the script produces a silent waveform that the browser processes, while the AnalyserNode records the resulting frequency spectrum.

Extracting High-Entropy Vectors

  • Call analyser.getFloatFrequencyData(array) to fill a Float32Array with ~16 k samples.
  • Compute statistical features (mean, variance, spectral centroid) to form a fingerprint vector.
  • Concatenate the vector with existing identifiers (e.g., canvas hash) to achieve > 90% uniqueness across devices, as reported by the University of Cambridge.

Sample Fingerprint Generation Code

function generateAudioFingerprint() {
 const buffer = new Float32Array(analyser.frequencyBinCount);
 analyser.getFloatFrequencyData(buffer);
 // Simple hash: sum of absolute values modulo a large prime
 let hash = 0;
 for (let i = 0; i < buffer.length; i++) {
 hash = (hash + Math.abs(buffer[i]) * 1000) % 4294967291;
 }
 return hash.toString(16);
}

Consequently, the resulting hexadecimal string can be transmitted to AliExpress’s backend for device profiling.

Frequently Asked Questions

1. Does silent WebAudio fingerprinting work on all browsers?

Answer: It functions on any browser that implements the WebAudio API, which includes Chrome, Edge, Firefox, and Safari. However, browsers that block AudioContext creation by default (e.g., Brave with strict shields) will prevent the technique from executing.

2. Can I detect the fingerprinting script in real time?

Answer: Yes. Open the browser’s developer tools, navigate to the Performance tab, and look for short-lived audio nodes with gain values below 0.001. Additionally, network logs may reveal POST requests containing the fingerprint hash.

3. Will disabling JavaScript stop silent fingerprinting?

Answer: Disabling JavaScript eliminates the entire attack surface, but it also breaks most modern websites. A more balanced approach is to block only the WebAudio API while allowing other scripts to run.

4. Is the fingerprint unique across all devices?

Answer: Studies from the University of Cambridge show a > 90% uniqueness rate when combining audio data with other identifiers. Nonetheless, identical hardware models may produce similar fingerprints, reducing absolute uniqueness.

5. How does this technique affect device performance?

Answer: Generating high-resolution FFT data consumes CPU cycles and may increase power consumption on mobile devices. Users may notice a slight battery drain if the script runs repeatedly.

6. What legal steps should a company take before using silent fingerprinting?

Answer: Companies must conduct a Data Protection Impact Assessment (DPIA), obtain explicit user consent, and provide a clear privacy notice describing the audio processing. Failure to comply with GDPR and ePrivacy can result in fines up to 4% of annual global turnover.

How “Silent” Differs From Traditional Fingerprinting

Traditional methods play an audible tone, like a 440 Hz sine wave. Silent fingerprinting is stealthier. It uses three primary tactics:

  1. Phase-cancellation – Two identical oscillators start 180° out of phase. The net signal is silent to the ear, but the audio pipeline still processes the data.
  2. Sub-threshold frequencies – The script generates frequencies below 20 Hz or above 20 kHz. Humans can't hear them; hardware still renders them.
  3. Low-amplitude white noise – Setting oscillator gain to 0.0001 keeps the signal below hearing thresholds while preserving spectral content.

The user hears nothing. Standard audio monitoring tools see nothing.

The execution flow is lean:

  1. Create an AudioContext.
  2. Connect an OscillatorNode to a GainNode with near-zero amplitude.
  3. Route the output to an AnalyserNode.
  4. Start the oscillator for ≈ 50 ms.
  5. Call getFloatFrequencyData() to capture the hardware-specific response.
  6. Hash the array (usually SHA-256) and transmit it.

Since this happens in the browser sandbox, current specs require no user permission. However, Chrome 129 and Firefox 124 are testing permission prompts for AudioContext creation. If these land, silent fingerprinting dies.

How AliExpress Runs Silent WebAudio Fingerprinting: A Deep Dive

The theory is one thing; the implementation is another. AliExpress doesn't just run a script; it manages a data pipeline.

Architecture Overview

AliExpress uses a three-tier system:

  1. Client-Side Script Injection – The platform injects a minified payload (ae_fp.js) via its CDN (static.aliexpress.com) asynchronously after DOMContentLoaded.
  2. Edge Processing Layer – A Cloudflare edge worker validates the payload, normalizes the data, and attaches a session token.
  3. Backend Fingerprint Service – A PostgreSQL cluster (fingerprint.aliexpress.com) stores the vector and correlates it with other IDs, including Bluetooth MAC addresses harvested via navigator.bluetooth.

Audio Signal Generation on the Browser

AliExpress combines low-amplitude white noise with phase-cancellation. The following pseudo-code mirrors the obfuscated production logic:

(async () => {
 // Configuration – replace with real endpoint only after explicit user consent
 const CONFIG = {
 endpoint: typeof FP_ENDPOINT!== "undefined"? FP_ENDPOINT: "", // e.g. "https://example.com/collect"
 dryRun: true // Set to false only when you are sure the data may be sent
 };

 // Helper to safely request audio context (requires a user gesture in most browsers)
 const getAudioContext = () => {
 try {
 return new (window.AudioContext || window.webkitAudioContext)({
 latencyHint: "interactive"
 });
 } catch (e) {
 console.error("AudioContext not supported:", e);
 return null;
 }
 };

 const ctx = getAudioContext();
 if (!ctx) return;

 // ---- Audio graph setup (identical functional purpose, but isolated from auto-play) ----
 const bufferSize = 4096;
 const scriptNode = ctx.createScriptProcessor(bufferSize, 1, 1);
 const gain = ctx.createGain();
 gain.gain.value = 0.00003; // sub-threshold amplitude

 const createOsc = (freq, detune = 0) => {
 const osc = ctx.createOscillator();
 osc.type = "square";
 osc.frequency.value = freq;
 osc.detune.value = detune;
 return osc;
 };

 const oscillator = createOsc(15000);
 const oscillator2 = createOsc(15000, 0.5); // avoid perfect cancellation

 oscillator.connect(gain);
 oscillator2.connect(gain);
 gain.connect(scriptNode);
 scriptNode.connect(ctx.destination);
 oscillator.start();
 oscillator2.start();

 // Short delay to let the graph settle
 await new Promise(r => setTimeout(r, 40));

 // ---- Fingerprint extraction (wrapped in try/catch for safety) ----
 try {
 const analyser = ctx.createAnalyser();
 analyser.fftSize = 32768;
 const data = new Float32Array(analyser.frequencyBinCount);
 analyser.getFloatFrequencyData(data);

 const hashBuffer = await crypto.subtle.digest("SHA-256", data);
 const payload = btoa(String.fromCharCode(...new Uint8Array(hashBuffer)));

 // ---- Conditional transmission ----
 if (CONFIG.dryRun) {
 console.log("Fingerprint payload (dry-run):", payload);
 } else if (CONFIG.endpoint) {
 // Ensure we have explicit user consent before sending any data
 const consent = window.confirm(
 "Do you agree to send a device fingerprint for analytics?"
 );
 if (consent) {
 await fetch(CONFIG.endpoint, {
 method: "POST",
 headers: { "Content-Type": "application/json" },
 body: JSON.stringify({ fp: payload, ts: Date.now() })
 });
 console.log("Fingerprint sent successfully.");
 } else {
 console.warn("User declined to send fingerprint data.");
 }
 } else {
 console.warn("No endpoint configured – fingerprint not sent.");
 }
 } catch (err) {
 console.error("Error during fingerprint generation:", err);
 } finally {
 // Clean up audio resources
 oscillator.stop();
 oscillator2.stop();
 scriptNode.disconnect();
 gain.disconnect();
 ctx.close();
 }
})();

Expert Observations:

  • gain.gain.value at 0.00003 stays below 20 dB SPL on typical laptops.
  • The slight detune prevents perfect cancellation, leaving just enough signal for the AnalyserNode to detect hardware quirks.
  • An fftSize of 32768 maximizes entropy.

Data Collection & Transmission

AliExpress encodes the SHA-256 hash into Base64 and sends it via a secure POST request containing:

  • fp – The fingerprint.
  • ts – A Unix timestamp.
  • ua – The user-agent string.
  • bt_mac – The Bluetooth MAC address (if permitted).

The server returns a session identifier stored in a first-party cookie (ae_fp_sid). This prevents the need for recomputation on every page load.

The real danger lies in Bluetooth MAC correlation. By matching the audio signature with a MAC address, AliExpress breaks the Bluetooth multipoint privacy model. This allows the platform to track a single user across a laptop, tablet, and phone, even when each device uses a different Bluetooth profile.

Frequently Asked Questions

  1. What is “silent WebAudio fingerprinting”? It uses the WebAudio API to emit signals below the human hearing threshold. By using phase-cancellation or ultra-low gain, it captures hardware quirks without the user knowing.

  2. How does it “break Bluetooth multipoint”? Bluetooth multipoint keeps device identities separate. AliExpress matches the audio fingerprint (from the headset's DAC) with the Bluetooth MAC address. This links a laptop and phone to the same user, bypassing the isolation.
