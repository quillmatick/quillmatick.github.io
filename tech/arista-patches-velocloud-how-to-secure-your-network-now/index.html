Understanding the Vulnerability

What Is the “maximum severity” Command Injection?

  • Definition: The maximum severity command tells the VeloCloud Orchestrator to retrieve the highest severity alert from its monitoring engine.
  • Attack vector: Threat actors inject malicious payloads into the command's parameters. Because the system fails to validate input, it executes arbitrary shell commands on the host..
